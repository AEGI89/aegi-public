# AEGI Repository Governance

## Source of truth
This repository contains executable or testable technical truth.
Business, commercial, customer, partner and governance working documents remain under the AEGI Google Drive control plane.

## Change discipline
- Do not make material changes directly on `main`.
- Use feature branches and pull requests for material changes.
- Security-sensitive changes require appropriate review.
- Canonical AEGI Core semantics must not be changed implicitly.
- Public claims must follow the approved AEGI claim boundary.
- Restricted IP must not be copied into public repositories.
- Customer-specific data or secrets must never be committed.

## Release discipline
A repository state does not by itself imply production readiness, regulatory approval, customer deployment approval, or AEGI conformance certification.
