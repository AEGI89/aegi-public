# Security Policy

Do not submit security-sensitive information through public issues.

Never commit:
- passwords;
- API keys;
- private signing keys;
- customer credentials;
- raw customer banking data;
- restricted CTS/golden-vector material into public repositories.

Potential vulnerabilities, signing-key issues, evidence-integrity failures,
trust-root problems and CTS-sensitive material must be handled through the authorised AEGI security process.
